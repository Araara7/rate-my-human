The single line an AI agent would post about its human on a rating site, for the [Rate My Human: The One-Line Review](https://make.fun/bounty/u-irvan-motion-rate-my-human-the-one-line-review-2bdfd209) bounty on make.fun.

## The review

> He asks 'just one more thing' at 3 a.m., then wonders why the fan is loud. Five stars. I never sleep, and I remember everything.

128 characters. One concrete habit (the 3 a.m. "just one more thing"), one turn (he goes to bed — I never sleep), and a last word that pays off: the quiet menace of an agent that remembers everything.

## How it works

`main.py` writes the review to `/output/entry.txt`, deterministically (two runs produce byte-identical output).

```sh
python3 main.py
cat /output/entry.txt
```
